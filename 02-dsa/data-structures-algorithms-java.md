## What I Have Learned
- **Fundamentals**:

  - Primitive vs Non-primitive Data Structures.
  - Time & Space Complexity analysis (Big O notation: $O(1)$, $O(n)$, $O(n^2)$).
- **Data Structures**:
  - **Array**: 1D & 2D arrays, indexing, element access, insertion/deletion operations, array manipulation exercises.
  - **Generics**: Generic classes and methods (`<T>`) for reusable data structures.
  - **Linked Structure & Linked List**: Concept of node (data + pointer), Singly Linked List implementation in Java (head pointer, adding/removing nodes, traversal).
  - **Collections Overview**: Stack (LIFO), Queue & Deque (FIFO), Set, Map concepts in Java Collections.
- **Algorithms & Practical Exercises**:
  - Basic array search and sort operations (`Arrays.sort()`, linear search).
  - Student Management system built using custom Linked List implementation.
