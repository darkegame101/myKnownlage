# Course Summary: C001 — Lập trình Java (Java Core)

## Course Overview
- **Course ID**: C001
- **Provider**: TITV
- **Course Name**: Lập trình Java (Java Core)
- **URL**: [https://titv.vn/courses-page/lap-trinh-java-java-core/](https://titv.vn/courses-page/lap-trinh-java-java-core/)
- **Status**: Completed
- **Total Lectures**: 104 Video Lessons

## Topics Covered
1. **Environment Setup & Syntax**: JDK & Eclipse installation, Java class structure, variables, primitive types, constants, comments, compiler error handling.
2. **Operators & Control Flow**: Scanner input, data type casting, arithmetic/logical operators, Math class, `if-else`, `switch-case`, `for`, `while`, `do-while` loops, `break`, `continue`, `return`.
3. **Array & OOP Fundamentals**: 1D arrays, OOP introduction, UML class diagrams, constructors, getters/setters, `toString()`, `equals()` and `hashCode()` contracts, OOP exercises (Book, Movie, Student, Computer management).
4. **Advanced OOP**: Single inheritance, `@Override`, `@Overload`, abstract classes, interfaces, packages, access modifiers (`public`, `protected`, default, `private`).
5. **Strings & Java Collections**: String methods, array copying, `Comparable` interface, Arrays utility methods, Date/Time classes, `Random`, `NumberFormat` (Tai Xiu mini-game), `Enum`, Java Collections (`ArrayList`, `Stack`, `Queue`, `Deque`, `Set`, `Map`, `Generics`).
6. **File I/O & Serialization**: File creation, properties, directory listing, delete, rename, copy, text file read/write, Object Serialization (`ObjectOutputStream`/`ObjectInputStream`), Zip/Unzip files.
7. **Java Swing GUI**: JFrame, JPanel, Layout Managers, Look & Feel, MVC Pattern, Event Handling, Fonts/Colors, JTextField, JTextArea, JScrollPane, Mouse events, graphics drawing, JMenu, JToolBar, Popup menu, JRadioButton, JCheckBox, JComboBox, JList, JOptionPane, JFileChooser, Drag & Drop GUI, Export JAR.
