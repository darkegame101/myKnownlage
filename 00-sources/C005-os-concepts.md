# Course Summary: C005 — Nguyên lý Hệ điều hành

## Course Overview
- **Course ID**: C005
- **Provider**: TITV
- **Course Name**: Nguyên lý Hệ điều hành
- **URL**: [https://titv.vn/courses-page/he-dieu-hanh/](https://titv.vn/courses-page/he-dieu-hanh/)
- **Status**: Completed
- **Total Lectures**: 16 Video Lessons

## Topics Covered
1. **Computer Organization & OS Overview**: Computer components, OS definition, OS services, System Calls (API), OS components (Kernel, Shell).
2. **Modern Operating Systems**: Overview of current OS architectures.
3. **Process Management**: Process concept, PCB, Process States, CPU Scheduling algorithms (FIFO, Round Robin, SJF).
4. **Synchronization & Deadlock**: Concurrent processes, Race conditions, Critical Section problem, Mutex, Semaphores, Deadlock 4 necessary conditions and prevention.
5. **Memory Management**: Memory hierarchy, Fixed and Variable Partitioning, Paging, Segmentation.
6. **File Systems**: File concepts, attributes, directory structures, file access methods.

## Topics Already Known Before Course
- Basic computer usage.

## New Knowledge Added
- Dual-mode CPU operation (User mode vs Kernel mode) and System Calls.
- Process Control Block (PCB), Process States, and CPU Scheduling mechanics.
- Race conditions, Process Synchronization, and Deadlock conditions.
- Memory partitioning, Paging, and Segmentation.

## Knowledge Deepened
