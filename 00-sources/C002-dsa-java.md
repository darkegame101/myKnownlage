# Course Summary: C002 — Cấu trúc dữ liệu và giải thuật Java

## Course Overview
- **Course ID**: C002
- **Provider**: TITV
- **Course Name**: Cấu trúc dữ liệu và giải thuật Java
- **URL**: [https://titv.vn/courses-page/video-cau-truc-du-lieu-va-giai-thuat-java/](https://titv.vn/courses-page/video-cau-truc-du-lieu-va-giai-thuat-java/)
- **Status**: Completed
- **Total Lectures**: 14 Video Lessons

## Topics Covered
1. **Introduction to DSA**: Why study Data Structures and Algorithms.
2. **Variables & Data Structures**: Data types vs Data structures.
3. **Array Data Structure**: 1D array operations, Array exercises, 2D array exercises.
4. **Generics**: Generic classes and methods in Java (`<T>`).
5. **Algorithm Analysis**: Overview of algorithms and Big O time complexity analysis.
6. **Collections Overview**: High-level introduction to Java Collections.
7. **Linked Structure & Linked List**: Node concept, Singly Linked List implementation, Singly Linked List exercises, Student Management using Linked List.

## Topics Already Known Before Course
- Basic array declaration from Java Core.

## New Knowledge Added
- Big O notation and time complexity concepts.
- Singly Linked List node pointer architecture.
- Custom implementation of Singly Linked List in Java.

## Knowledge Deepened
- 1D and 2D Array data manipulations.
- Generics usage for custom data structures.

## Practical Skills Added
- Implementing a Singly Linked List from scratch in Java.
- Building a Student Management system using a custom Linked List.

## Remaining Gaps
- Doubly Linked List, Circular Linked List.
- Binary Search Tree (BST), AVL Tree, Heap, Trie, Graph algorithms (BFS, DFS).
- Sorting algorithms from scratch (QuickSort, MergeSort, HeapSort).
- Searching algorithms (Binary Search).

## Knowledge Not Covered
- Dynamic Programming, Backtracking, Greedy Algorithms.
- Advanced Tree and Graph data structures.

## Resulting Skill Level
- **Theory**: 3/5
- **Practical**: 2/5
- **Troubleshooting**: 1/5
- **Design**: 1/5
