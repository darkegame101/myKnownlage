# Course Summary: C007 — Git và GitHub toàn tập

## Course Overview
- **Course ID**: C007
- **Provider**: TITV
- **Course Name**: Git và GitHub toàn tập
- **URL**: [https://titv.vn/courses-page/git-va-github-toan-tap/](https://titv.vn/courses-page/git-va-github-toan-tap/)
- **Status**: Completed
- **Total Lectures**: 24 Video Lessons

## Topics Covered
1. **Introduction & Environment**: Version Control Systems (VCS), installing Git, basic Terminal CLI navigation, initializing Git repo (`git init`), identity config (`git config`).
2. **Core Workflow**: 3 Git States (Working Directory, Staging, Repo), `git add`, `git commit`, `git status`, `git diff`, `git log`, `.gitignore` configuration.
3. **Branching & Merging**: Branch creation (`git branch`), checkout (`git checkout`, `git switch`), `git merge` (fast-forward, 3-way), `git rebase`, deleting branches (`git branch -d`).
4. **Undoing & Conflict Resolution**: Resolving Merge Conflicts, `git checkout <commit>`, `git reset` (soft, mixed, hard), `git revert`.
5. **GitHub & Remote Collaboration**: Creating GitHub account & repos, `git clone`, `git push`, `git pull`, `git remote`, Forking repositories, Pull Requests (PR), GitHub Desktop GUI, VS Code Git integration.

## Topics Already Known Before Course
- Basic terminal CLI commands (from C008 / Linux).

## New Knowledge Added
- Complete Git CLI version control workflow.
- Branching strategies, Fast-forward merge vs 3-way merge, Git rebase.
- Undoing history with `git reset` and `git revert`.
- GitHub collaboration flow: cloning, pushing, pulling, forking, and PRs.

## Knowledge Deepened
- Terminal command-line usage.

## Practical Skills Added
- Managing Git repositories via command line.
- Creating branches, rebasing commits, and resolving merge conflicts manually.
- Contributing to open-source or team projects via GitHub Pull Requests.

## Remaining Gaps
- `git reflog` disaster recovery.
- `git bisect` automated bug location.
- GitHub Actions CI/CD automated pipeline workflows.

## Knowledge Not Covered

- GPG Commit signing.
