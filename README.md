## 🎯 Scale Reference (0–5)
- **0**: Not learned.
- **1**: Terminology known.
- **2**: Concept understood.
- **3**: Mechanism understood (How & Why).
- **4**: Able to use / implement in labs & code.
- **5**: Troubleshoot / Design solution architectures.
